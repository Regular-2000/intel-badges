Intel Badge Finder

Quick rules & suffix cheat-sheet

Reading the number: i5-520M 3 digits = 1st gen · i5-8250U first digit = gen (2nd–9th) · i5-10210U, i7-12700H first two digits = gen (10th–14th) · i5-1035G1, i5-1135G7, i5-1235U 4 digits starting "1" = first two digits (10th–13th) · Ultra 7 155H first digit = Series (1/2/3).

SuffixMeaning
M / QM / MQMobile / quad-core mobile (1st–4th gen)
ULow-power ultrabook/business (15 W)
Y, Core MVery low power, fanless-type (tablets, 12" ultralights)
H / HQ / HKPerformance laptop (gaming / workstation); K = unlocked
G1/G4/G710th-gen Ice Lake & 11th-gen Tiger Lake; higher = better iGPU
P12th/13th gen, mid-power thin & light (28 W)
HXDesktop-class laptop chip (big gaming laptops)
VCore Ultra Series 2 Lunar Lake — RAM soldered on the CPU package
K / F / TDesktop: unlocked / no iGPU / low-power

vPro on the badge = business-managed chip (Latitude, EliteBook, ThinkPad T/X). It uses the same styling as its era, so it doesn't change the gen.

Celeron / Pentium / Atom stickers follow the same styling eras. Use them to guess the era only, not the performance.

Stickers are the weakest clue. Palmrests get swapped, badges get re-applied, and near-identical designs cover several gens (4th/5th, 6th–8th, 11th–14th, Ultra S1/S2). When the listing shows a model number (sticker on bottom, BIOS, "System" screen, CPU-Z), trust that instead.
